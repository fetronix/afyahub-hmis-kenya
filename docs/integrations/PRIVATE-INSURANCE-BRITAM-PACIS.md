# Private insurance: Britam, PACIS and CIC

**Operational status (28 October 2026):** These are independent payer definitions and adapter boundaries, not verified electronic connections. No authorized insurer API contract, sandbox test or production approval has been established in this repository. CIC has its own unsupported adapter; new providers start disabled with the manual adapter. See [the payer integration hub guide](payer-integration-hub.md) for current setup, permissions and evidence.

SUPER_ADMIN registers and assigns providers. A facility administrator may only activate a globally enabled provider assigned to that facility; facility users cannot register providers or change the global adapter. No default Britam/PACIS configuration is automatically seeded. Legacy facility settings and claims are preserved but require platform assignment review. Local settings must be reviewed against each facility's real agreement, particularly schemes, deadlines, benefit rules, coding systems and preauthorization requirements.

The module reuses existing patients, encounters, tariffs and invoices. It supports recorded membership, documented **manual** eligibility, locally configured benefit estimates, preauthorization and claim records, manual dispatch references, rejection correction and advice allocation. Policy data alone is not payer-confirmed eligibility; a successful connection would not be claim approval. An unavailable adapter is not `Ineligible`, and an estimate is not a reimbursement guarantee.

Claim preparation and submission do not mutate invoices. Advice does not create receipts. A billing user must separately record an evidenced insurer payment before a matching advice allocation can link it; no independent bank verification is implied. Mock/provider responses in tests are synthetic and are never sandbox evidence.

Britam, PACIS, CIC and SmartLink do not share an assumed contract. Public sources inspected include [Britam's manual medical claim guidance](https://ke.britam.com/help/file-a-claim/medical-insurance-claim), [PACIS's provider claim form](https://www.pacisinsurance.com/wp-content/uploads/2025/08/PACIS-Insurance-Medical-Cover-Preferred-Provider-Outpatient-Claim-Form.pdf), and [CIC's health insurance information](https://ke.cicinsurancegroup.com/top-questions-to-ask-before-choosing-cic-health-insurance/). These are not proof of a facility API. Obtain the actual insurer-approved contract, provider identifier, coding and tariff schedules, facility-specific credentials and written sandbox/production authorization before a dedicated adapter is implemented and enabled.
