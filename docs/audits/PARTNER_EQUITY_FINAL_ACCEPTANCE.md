## Reproduction (disposable local databases only)

Use a freshly provisioned **nonproduction** PostgreSQL instance. Apply repository migrations only to the disposable databases; do not point these commands at a live instance. The scripts neither reset nor migrate databases. The browser harness creates unique synthetic fixtures and does not delete existing data. It requires the exact database name and loopback host before connecting. Both unsafe-host and unsafe-database refusal paths were verified.

```bash
# After dependencies, repository migrations and browser runtime are prepared:
npm run build
npm run build:server
EQUITY_ACCEPTANCE_SYNTHETIC=YES \
SQL_HOST=127.0.0.1 SQL_PORT=<disposable-port> \
SQL_DB_NAME=equity_acceptance_synthetic_test \
SQL_ADMIN_USER=<disposable-user> SQL_ADMIN_PASSWORD=<disposable-password> \
SQL_SSL=false CHROME_EXECUTABLE_PATH=<chromium-path> \
node scripts/partner-equity-acceptance.mjs

# Optional separate PyMuPDF environment; not an application dependency:
python3 -m venv .tmp-tools/equity-pdf-inspection
.tmp-tools/equity-pdf-inspection/bin/pip install PyMuPDF
EQUITY_SOURCE_SCREENSHOT=<original-screenshot-path> \
.tmp-tools/equity-pdf-inspection/bin/python scripts/inspect-partner-equity-acceptance-exports.py
```

Set the browser runtime’s library path if required. `BROWSER_NO_SANDBOX=1` was used only for the disposable sandbox container. The screenshot environment variable is optional; omitting it skips image hash verification, not the saved-export value checks. Real PDF financial inspection is a separate step, not just a file-exists/button-visible assertion.

The initial regression run without PostgreSQL on default port5432 correctly announced DB unavailability; the separate explicit database run above executed **all11** DB tests successfully. Earlier browser harness attempts failed on download-buffer capture and a period-switch timing assumption. These harness issues were corrected; final exports were captured from completed browser downloads, the complete run exited0, and stale failure evidence was removed only after successful results were independently checked.

Downloaded CSV evidence retains the exporter’s original CRLF bytes. Staged whitespace validation uses `git -c core.whitespace=blank-at-eol,blank-at-eof,space-before-tab,cr-at-eol diff --cached --check` so valid CSV line endings are not rewritten as evidence.
